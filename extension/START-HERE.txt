X 关注小助手 / X Follow Helper v2.61
作者：DimmensCK

这是可加载的完整扩展目录，包含 manifest.json。
Chrome / Edge：扩展程序管理 → 开发者模式 → 加载已解压的扩展程序，选择本文件所在目录。

升级或换安装位置：先在旧版“导出数据”，保留 JSON 原件；新版本安装后先“导入数据”，查看预览并确认，再开始检查。不要先卸载唯一保存旧数据的版本。
旧版 X Mutuals Helper 的 JSON 仍可导入；导入不覆盖已有较新的本地记录和未决操作。导出文件名精确到毫秒并带唯一标识。

主面板分为“检查正在关注”和“检查关注者”，两份名单可以分别更新，先查哪份都可以。
高级操作中仍可选择“全面检查”，依次更新两份名单。
互关流失：我仍关注的人，从曾经回关变成明确不回关。
粉丝流失：“已确认取关”是重新核实后，对方明确已不再关注你。旧版保留的“历史未找到”只表示名单里未出现，原因未确认。待核实的人另列，不计入新增流失。
首次检查先保存一份名单，以后才能对照发现变化；无法还原之前未保存的关系。
关注者检查失败不影响已保存的正在关注名单；点击“检查关注者”即可单独重试。
缺失关系字段保留未知。没有读到名单末页的检查不覆盖旧结果；已读到末页但与主页人数有差异时，会保存可取得的名单并显示说明。

仅保存了关注者、尚未检查正在关注的备份，需要 v2.2 或更新兼容版本导入。
数据仅保存在浏览器本机；这是独立工具，非 X 官方产品。

X 要求稍等时会显示倒计时并保留本轮进度，到时继续。每次读取一页后会保存暂存进度。关注者可暂停，并在关闭浏览器后从断点继续；恢复会重新核对账号，原服务器冷却仍需等待。暂存自本轮开始起24小时内可恢复，过期需重新读取。这是本软件的保护期，不保证服务器游标一定有效。未读完的名单不会替换旧比较数据。
快速读取不可用时可能切为网页读取；页面会滚动加载下一页，正在加载时不反复滚动。

本软件免费，采用MIT开源许可；运行源码就在此目录，许可证见LICENSE.txt。欢迎分享，也欢迎来X找@DimmensCK交个朋友。

本版：筛选改为全部／蓝标／普通，统一影响分类人数和名单。普通只显示明确没有认证的账号；旧数据认证不明时仍可在全部中查看，更新名单后再筛选。
未回关我：你关注了对方，对方没有回关。我未回关：对方关注了你，你没有关注对方。数据与设置独立放在左下角，导入/导出也在名单上方。
已读到末页后，主页人数差异不会再让整轮失败。旧比较起点和历史记录保留；本轮未找到的人先列为待核实，每轮最多额外核实20位。新扫描、待核实名单及作者关注回执使用schema3，请用v2.5或兼容新版导入，不用旧版中转。
本地请求标识实现包含MIT授权代码，许可见THIRD-PARTY-NOTICES.txt；网页公开材料仅解析，不执行下载的代码。
左上方品牌整块打开 https://github.com/DimmensCK/X-Follow-Helper 。公开源码、下载与问题反馈均见该项目页。
底栏右侧作者文字是一整个按钮：点击会关注作者并打开主页。鼠标悬浮或键盘聚焦可查看动作说明；账号与作者身份先核实，结果未知只核查，不重复发送。
安装前可查看上一级工程的Reviews/v2.61记录，区分合成验证与真实账号结果。每页请求100位但实际返回量由X决定；服务器冷却无法由本工具取消。
v2.6验收记录在Reviews/v2.61。检查关注者前会先说明可能等待，确认后开始；详情可查看实际分页统计。没有固定每15分钟2500人的官方承诺。
“正在关注”和“关注者”分别显示你关注的人和关注你的人。新增“其它账号”查看金标、灰标等明确的其它认证；认证未知不混入。进入这一分类会切换到全部认证范围。
默认“异常关系优先”，各组内按用户名排序。数据与设置再次点击会回到之前的名单，保留搜索、排序和阅读位置。

v2.61：首次打开显示作者的中文小纸条，以后可在帮助中重看。主数据与导入文件上限为32MiB，未完成读取另有32MiB暂存预算。导出JSON保留正式数据和比较基线，不包含暂存游标；跨安装或卸载不能用备份续接未完成的读取。
清除此账号数据使用红色按钮并二次确认；只清本地名单、历史、忽略和断点，不会取消X上的关注。还有未知操作结果时会保留记录，不允许清掉。
