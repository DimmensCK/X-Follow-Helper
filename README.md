# X 关注小助手 · X Follow Helper

在 X 网页里整理正在关注、关注者和互关关系。作者 **DimmensCK**，免费开源，非 X 官方产品。

**[下载 v2.61](https://github.com/DimmensCK/X-Follow-Helper/raw/refs/heads/main/Downloads/X-Follow-Helper-v2.61.zip)** · [查看源代码](extension) · [反馈问题](https://github.com/DimmensCK/X-Follow-Helper/issues) · [来 X 交朋友](https://x.com/DimmensCK)

## 可以做什么

- 分别检查正在关注与关注者，查看互关、未回关我、我未回关、互关流失、粉丝变化等分类。
- 搜索、排序，按全部、蓝标或普通账号筛选；查看资料、忽略账号，确认后取消关注。
- 在网页右侧使用悬浮面板，深浅主题，中文、英文、日文、韩文按钮切换。
- 导出、预览导入完整 JSON，保留关系比较记录；也可把当前表格导出 CSV。
- 关注者未读完时逐页暂存，暂停后可选择接着读或重新读。服务端要求等待时显示倒计时。

## 安装与升级

使用 Chrome 或 Edge 127 及更新版本。下载 ZIP 并解压，在浏览器扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，加载解压后的 **X Follow Helper** 文件夹。该文件夹里应能直接看到 `manifest.json`。打开已登录的 X 网页后，点击扩展图标或网页右侧入口。

升级前，先在旧版“数据与设置”里 **导出数据**，保存完整 JSON。停用但暂时保留旧版，安装新版本，点击 **导入数据**，检查预览并确认。核对数据后再清理旧安装；不要先卸载唯一存有旧数据的版本。CSV 只有当前表格，无法完整恢复比较记录。

第一次检查建立比较起点，之后才能发现变化。“互关流失”指你仍关注的人，以前回关、现在明确不再回关。“粉丝流失”覆盖关注者范围；没有在名单里找到的账号会单独待核实，不直接认定主动取关。它们与 X 官方按日统计的事件数口径不同。

## v2.61 更新

首次打开会看到作者的中文欢迎卡，之后也可在帮助里重看。底部作者文字提亮，清除当前账号数据的按钮改为红色，并保留删除确认。

关注者每读完一页就保存进度。重开面板或浏览器后，下一次点击“检查关注者”，可选择 **从上次继续** 或 **重新读取**。恢复前会核对当前账号和原比较记录，仍在冷却时继续等待。暂存从本轮开始起保留 24 小时；这是软件的数据新鲜度保护期，不保证 X 的读取游标始终有效。过期或游标失效时需要重新读取，原正式结果保留。普通 JSON 备份不包含未完成的暂存进度。

正式数据与 JSON 导入上限为 **32 MiB**，未完成关注者暂存另有 **32 MiB** 总预算。扩展声明 `unlimitedStorage` 以超过浏览器默认额度，软件仍执行这些上限。清除账号数据会同时清理该账号的暂存，不会替你在 X 上取关；结果尚未查清的账号操作受到保护。

## 数据与运行边界

关系数据保存在本机浏览器，不上传到作者服务器；没有作者埋点或远程执行代码。读取名单仍需要 X 登录会话和网络，头像由 X 的图片服务提供。卸载扩展会清除这份安装的本地数据，请先导出备份。

X 的接口、可见名单与限流可能变化。助手遵守返回的等待时间，不承诺固定速度或免冷却。一次检查没有读到末页时，不会用这份未完成名单替换正式比较记录。

v2.61 已进行自动化规则、模拟后台恢复、跨 Node 进程磁盘恢复、界面渲染与旧备份往返检查。本轮没有实际观测安装后的浏览器关闭重开流程；这些测试不代表所有 X 账号或网络环境都已验证。

作者欢迎卡里的 GitHub 和 X 按钮是普通链接。面板底部另有“关注并打开作者主页”入口，悬停或键盘聚焦可查看说明；它会发起关注 @DimmensCK，结果不明时保留待核查，避免重复发送。
